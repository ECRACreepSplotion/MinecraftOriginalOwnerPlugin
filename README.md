# MinecraftOriginalOwnerPlugin
OwnershipTracker is a Minecraft Paper plugin designed to create a persistent ownership and theft system for valuable equipment. Certain valuable Minecraft items are assigned a rightful owner when they first come into a player's possession. If another player possesses that item, the plugin identifies it as stolen, records the ownership history, and provides mechanics for transferring ownership or tracking down the rightful owner. The plugin has a display, modifying the item's lore to tell the player whether they originally own the item or if it was stolen. Such items that are eligible for tracking are tools, armor pieces, and other equipment such as maces or elytras.
